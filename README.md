# MimiBox

Прокси-клиент для Windows на ядре **Xray-core** (VLESS / VMess / Trojan / Shadowsocks)
с монохромным интерфейсом «жидкое стекло»: чёрно-белое оформление, которое **само
следует теме системы** (авто → светлая → тёмная), русский и английский язык,
iOS-переключатели и pill-кнопки. Логику гоняет Xray, интерфейс — на веб-движке
Edge WebView2 (встроен в Windows 10/11, устанавливать ничего не нужно).

Помимо VPN в приложении живут встроенный **Telegram-мессенджер**, **плагины**,
виртуальный питомец **Серийчик**, новости канала, режим «игры» и глубокая
кастомизация интерфейса.

> Имя exe и папки данных — `MimiBox.exe`, `%APPDATA%\MimiBox`. При обновлении
> со старого имени (`LDK2ray.exe`, `%APPDATA%\LDK2ray`) настройки, подписка,
> Telegram-сессия и плагины переносятся автоматически при первом запуске.

## Что умеет

### Два режима, можно включить оба сразу

На главном экране две плитки:

- **Прокси** — системный прокси Windows. Через VPN пойдут браузеры и программы,
  которые уважают системные настройки. Права администратора не нужны.
- **Туннель** — виртуальный сетевой адаптер (Wintun + tun2socks). Через VPN пойдёт
  **весь** трафик системы, включая игры и приложения, которые системный прокси
  игнорируют. **Нужны права администратора** — приложение само предложит
  перезапуститься, Windows покажет обычный запрос UAC.

Переключаются на лету: если соединение уже поднято, разрывать его не нужно.

### Маршрутизация и исключения

Вкладка **Маршруты**:

- **Глобальный** — весь трафик в VPN;
- **По правилам** — российские сайты и IP идут напрямую, остальное через VPN;
- **Прямой** — VPN не используется.

Плюс два списка (по одной записи на строку), которые работают в любом режиме
и одинаково для прокси и для туннеля:

- **Сайты в обход VPN** — `gosuslugi.ru`, `*.sberbank.ru`, `192.168.50.0/24`,
  можно и готовые списки вроде `geosite:category-ru`;
- **Заблокировать** — этим адресам доступ закрывается совсем.

### Подписка

При импорте приложение читает заголовок `subscription-userinfo`, который отдают
панели (Marzban, 3x-ui, Remnawave и другие). В профиле видно:

- сколько гигабайт потрачено и сколько осталось (с полосой расхода);
- до какой даты действует подписка и сколько дней осталось;
- когда список серверов обновлялся, и кнопка «Обновить подписку».

### Скорость

Счётчик входящей и исходящей скорости — в шапке окна и в подсказке иконки в трее
(наведите курсор). Данные берутся из встроенной статистики Xray.

### Профиль Telegram

Введите свой `@username` — приложение подтянет имя и аватарку с публичной страницы
`t.me` и покажет их в профиле. Аккаунт должен быть публичным (иметь юзернейм).

### Telegram-мессенджер

Встроенный клиент Telegram (Telethon, сессия живёт в `%APPDATA%\MimiBox`):

- список чатов, поиск, счётчики непрочитанного;
- сообщения с фото, видео, файлами, **голосовыми** (с длительностью и инлайн-плеем),
  стикерами и GIF, премиум-эмодзи;
- серверный пикер стикеров / GIF / эмодзи;
- контекст-меню: ответить / изменить / удалить;
- просмотр фото/видео/аудио встроенным вьюером.

Чтобы подключить аккаунт, нужны `api_id` и `api_hash` с `my.telegram.org`
(Настройки → Telegram). Данные хранятся только локально.

### Плагины

Папка `%APPDATA%\MimiBox\plugins` — простые скрипты-расширения мессенджера,
которые подключаются к событиям (например, автоперевод, декорации к сообщениям).
Включаются/выключаются в интерфейсе.

### Серийчик

Виртуальный питомец с уровнями (фото меняется по мере прокачки: 1–50, 51–100,
101–150, 151+), который:

- получает **еду** и меняет сытость и настроение;
- копит **банк** (внутренние очки);
- принимает **своё фото** (прозрачный PNG) — показывается вместо стандартного.

### Новости

Приложение следит за Telegram-каналом и показывает баннер с новыми постами
(кнопки «Открыть», «Отметить прочитанным»). Канал настраивается в коде, уведомления
можно отключить в Настройках.

### Игровой режим

Включается в Настройках. Приглушает собственные фоновые подсистемы приложения
(мессенджер, фоновые сканы новостей), освобождая память и CPU для игры. Свои
процессы системы при этом не трогаются.

### Кастомизация

- Тема: **авто** (по системе) / светлая / тёмная, плюс собственные цвета
  фона, текста, акцента и поверхностей;
- **Сцены** фона (сакура, звёзды, улица) или своё изображение;
- шрифт: встроенный Manrope, загруженный `.ttf` или системный;
- снежинки на подключённом сервере (можно выключить);
- привязка чатов мессенджера к адресатам.

### Автозапуск и трей

- **Автозапуск** при входе в Windows (запись в реестр);
- при закрытии — сворачивание в **трей** вместо выхода (настраивается),
  можно стартовать сразу свёрнутым;
- **высокий приоритет** процесса (лечит вялый старт).

### Живучесть после перезагрузки

Если ПК выключили или перезагрузили с работающим VPN, системный прокси в реестре
остаётся включённым, а ядро уже не работает — сайты не открываются, пока не снять
галочку «Использовать прокси-сервер для локальной сети» вручную. MimiBox при
старте **сам находит и снимает такой «зависший» прокси** (проверяет, что он указывает
на порт приложения, что порт больше никто не слушает, и выключает; чужие прокси
и живое подключение не трогает).

## Как собрать `MimiBox.exe`

### 0. Один раз — поставить Python 3.12

pywebview на Windows пока не дружит с Python 3.14, поэтому собираем на 3.12.
Открой cmd и выполни:

```
py install 3.12
```

(на итоговый exe версия сборки не влияет — он самодостаточный).

### 1. Ядро и вспомогательные файлы

В папке проекта должны лежать:

| Файл | Зачем | Где взять |
|---|---|---|
| `xray.exe` | ядро прокси | [Xray-core releases](https://github.com/XTLS/Xray-core/releases) → `Xray-windows-64.zip` |
| `tun2socks.exe` | режим «Туннель» | [tun2socks releases](https://github.com/xjasonlyu/tun2socks/releases) → `tun2socks-windows-amd64.zip` |
| `wintun.dll` | виртуальный адаптер | [wintun.net](https://www.wintun.net/) |
| `geoip.dat`, `geosite.dat` | базы для маршрутизации | репозиторий Xray |

В git-репозитории этих файлов нет (они игнорируются) — они кладутся рядом с
приложением при сборке. В установщик попадают из `releases\MimiBox\`.

### 2. Собрать

Дважды кликни **`build.bat`** (или запусти из cmd). Он поставит зависимости
и соберёт `dist\MimiBox\`. Первая сборка — 2–4 минуты.

## Установщик для рассылки

Дважды кликни **`installer\build_installer.bat`**. Он сам соберёт приложение,
положит рядом ядро и geo-файлы, поставит Inno Setup (через winget, если его нет)
и скомпилирует установщик:

```
installer\Output\MimiBox-Setup.exe
```

Ставится для текущего пользователя, без прав администратора. Получатель просто
запускает и жмёт «Далее».

> При удалении программы настройки и список серверов в `%APPDATA%\MimiBox`
> **не стираются** — обновление часто идёт через «удалить и поставить заново»,
> и терять из-за этого подписку пользователя незачем.

**Без Inno Setup / winget.** Положи `installer\MimiBox-portable-setup.bat` и всё
содержимое `dist\MimiBox\` в одну папку, заархивируй и отправь. Человек распакует
и запустит `.bat` — приложение установится в `%LOCALAPPDATA%\Programs\MimiBox`
с ярлыками. Тоже без администратора.

Готовые сборки — в разделе [Releases](https://github.com/mimidevil-vpn/MimiBox/releases).

## Запуск

Запусти `dist\MimiBox\MimiBox.exe` (или установи через Setup.exe).

- **Добавить** → вставь ссылки `vless://…` (по одной на строку) или ссылку на
  подписку → импорт.
- **Серверы** → выбери сервер → **Подключиться**. Кнопка «Пинг всех» покажет задержки.
- На главном экране — плитки **Прокси** и **Туннель**.
- Справа вверху — переключатели **темы** (солнце/луна) и **языка** (RU/EN).
- **Мессенджер** → подключи Telegram по `api_id`/`api_hash`, открой чат, отвечай
  на сообщения, листай стикеры и GIF.
- **Маршруты** → режим и списки исключений.
- **Настройки** → порты, приоритет процесса, трей, DNS туннеля, путь к xray,
  автозапуск, игровой режим, кастомизация.
- **Логи** → вывод Xray и туннеля, если что-то не подключается.

## Если что-то не так

- **Окно пустое / белое.** Значит нет среды **WebView2**. На Windows 11 она есть
  всегда; на старой Windows 10 поставь «Microsoft Edge WebView2 Runtime» с сайта
  Microsoft.
- **Приложение запускается вяло.** Настройки → **Высокий приоритет**.
- **«xray.exe не найден»** (в Настройках красным). Положи `xray.exe` в папку
  с приложением, либо укажи полный путь в Настройки → Путь к xray.exe.
- **Туннель не включается.** Нужны права администратора — нажми «Перезапустить»
  в жёлтом баннере. Проверь, что рядом с приложением лежат `tun2socks.exe`
  и `wintun.dll`, и что антивирус их не блокирует.
- **После перезагрузки ПК нет интернета.** Это «зависший» системный прокси от
  прошлого сеанса. Запусти MimiBox — приложение снимет его автоматически; если
  интернет нужен до запуска: Параметры → Сеть и Интернет → Прокси → выключи
  «Использовать прокси-сервер».
- **Не подключается.** Вкладка «Логи» — там причина от ядра Xray.
- **Настройки не сохраняются.** Настройки → **Папка с данными**: там `app.log`,
  в нём написана точная причина. Приложение также покажет баннер с текстом ошибки.
- **Антивирус ругается на exe.** Типичное ложное срабатывание PyInstaller.
  Сборка идёт с `--noupx` — с UPX срабатываний заметно больше.

## Отладка (если exe собрался, но окно не открывается)

Проще всего запустить без сборки — среда уже установлена:

```
py -3.12 -m pip install -r requirements.txt
py -3.12 main.py
```

Если появится ошибка в консоли — по ней будет ясно, что чинить.

## Структура

```
main.py          — окно pywebview, трей, колбэки
api.py           — мост JS <-> Python: подключение, режимы, настройки, мессенджер, Серийчик
ui/index.html    — весь интерфейс (HTML/CSS/JS, темы, языки, анимации)
parsing.py       — разбор ссылок, подписок и заголовка subscription-userinfo
xray_core.py     — конфиг Xray, маршрутизация, запуск ядра, статистика трафика
tun.py           — режим «Туннель»: tun2socks, маршруты, права администратора
tg_link.py       — привязка Telegram по @username
tg_client.py     — встроенный Telegram-мессенджер (Telethon)
plugins.py       — плагины мессенджера
win_proxy.py     — системный прокси Windows (+ авто-очистка «зависшего» прокси)
storage.py       — пути, атомарное сохранение настроек и серверов, app.log
build.bat        — сборка приложения
requirements.txt — зависимости
installer/       — сборка установщика:
  MimiBox.iss                 — скрипт Inno Setup (per-user, без админа)
  build_installer.bat         — приложение + установщик одной командой
  MimiBox-portable-setup.bat  — запасной установщик без сторонних программ
```
