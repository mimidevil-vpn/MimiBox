Спасибо, что тестируешь приложение! Внутри всё уже готово к работе.

КАК ЗАПУСТИТЬ (2 варианта)
--------------------------

Вариант 1 — просто запустить (без установки):
  1. Открой папку приложения
  2. Запусти  LDK2ray.exe
  Всё. Приложение работает прямо из папки.

Вариант 2 — установить в систему (появится ярлык на рабочем столе):
  1. Запусти  LDK2ray-Setup.exe
  2. Нажимай «Далее» — установка пройдёт сама, без прав администратора.

ПЕРВЫЙ ЗАПУСК
-------------
  • Откроется приветственный экран. Нажми «Продолжить».
  • Дальше вкладка «Добавить» → вставь свой ключ (vless://…, vmess://…, trojan://…, ss://…, ssr://…)
    или ссылку на любую подписку (Clash, base64, plain) → «Импортировать».
  • Вкладка «Серверы» → выбери сервер → «Подключиться».

ТРЕЙ (значок у часов)
---------------------
По умолчанию при нажатии «крестика» приложение сворачивается в трей и продолжает
работать. Клик по значку — открыть окно, правый клик → «Выход» — полностью закрыть.
Поведение можно изменить в «Настройки» (Сворачивать в трей / Запускать свёрнутым).

ЕСЛИ УЖЕ ЗАПУЩЕН ДРУГОЙ VPN
---------------------------
Если открыт сторонний VPN (Happ, NekoRay, Clash и т.п.) — приложение покажет
предупреждение. Отключи сторонний сервис, иначе возможны конфликты подключения.

ЕСЛИ ОКНО ПУСТОЕ / БЕЛОЕ
------------------------
Нужен «Microsoft Edge WebView2 Runtime». На Windows 11 он есть всегда.
На старой Windows 10 — поставь его с сайта Microsoft (бесплатно) и запусти снова.
